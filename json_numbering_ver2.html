Scenario → command.json

JSONナンバリング

1行＝1シナリオ。CNOを連番で振り、command.json を出力します。

Excelの範囲をコピーして、貼り付けたい先頭セルで Ctrl+V

出力プレビュー







  
使い方

  
    
    
  1. 表に値を入力する（Commentから右はExcelのDataシートと同じ並び。Excelの範囲はCommentのセルに貼り付けます）。
    2. 
    
  2. SNO既定値とCNO開始番号を入れる。明細のSNO・CNOが空欄の行は自動で決まります（SNOは既定値、CNOは前の行＋1。先頭行はCNO開始番号）。
    3. 
    
  3. 「command.json を保存」を押す。
    4. 
  

  
作成済みの command.json も「ファイルから読込」で読み込めます。SNO・CNOは読み込んだ値のまま各行に入ります。PRVSNO・PRVCNOは出力時に前の行から計算し直すので、ファイルの値と合わない行があれば読込時にお知らせします。

  
行の操作

  
各行の左端にボタンがあります（行にカーソルを置くか、マウスを乗せると濃くなります）。CNOが空欄の行は前の行＋1で毎回計算し直すので、挿入・複製・並べ替えのあとに振り直す作業は要りません（複製した行のCNOは空欄になります）。CNOを入れた行は、その値のまま出力します。

  
    
    
  • ↑+ 上に挿入 ／ ↓+ 下に挿入 — Ctrl+Enter で下に、Ctrl+Shift+Enter で上に
    • 
    
  • ⧉ 複製 — Ctrl+D。似たシナリオを1行だけ変えて足すとき用
    • 
    
  • ▲ ▼ 1行ずつ移動 — Alt+↑ / Alt+↓
    • 
    
  • × 削除
    • 
  


  
マクロと揃えている挙動

  
    
    
  • 出力対象はCommentが入っている最後の行まで。それ以降の行は、数値が入っていても出力されません。
    • 
    
  • 途中のComment空欄行はスキップされず"Comment":""として出力されます（左端に▲を表示）。
    • 
    
  • 空欄の数値項目は 0 に置き換わります（SNO・CNOは上の自動の値）。
    • 
    
  • PRVSNO・PRVCNOは前の行のSNO・CNO（先頭行は自分のSNOとCNO−1）。
    • 
    
  • ACAFが空欄なら CoordCorrectInfo は {} になります。
    • 
    
  • 改行コードはCRLF、文字コードはBOM付きUTF-8。
    • 
  

  
「Commentをエスケープ」は元マクロには無い追加分です。Commentに " や \ を使うとマクロの出力はJSONとして壊れるので、必要なときだけ入れてください。
