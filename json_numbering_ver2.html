Scenario → command.json

JSONナンバリング

1行＝1シナリオ。CNOを連番で振り、command.json を出力します。

Excelの範囲をコピーして、貼り付けたい先頭セルで Ctrl+V

出力プレビュー







  
使い方

  
    
    
  1. 表に値を入力する（ExcelのDataシートと同じ並び）。
    2. 
    
  2. CNO開始番号を入れる。
    3. 
    
  3. 「command.json を保存」を押す。
    4. 
  

  
行の操作

  
各行の左端にボタンがあります（行にカーソルを置くか、マウスを乗せると濃くなります）。CNOは行の並び順から毎回計算し直すので、挿入・複製・並べ替えのあとに振り直す作業は要りません。

  
    
    
  • ↑+ 上に挿入 ／ ↓+ 下に挿入 — Ctrl+Enter で下に、Ctrl+Shift+Enter で上に
    • 
    
  • ⧉ 複製 — Ctrl+D。似たシナリオを1行だけ変えて足すとき用
    • 
    
  • ▲ ▼ 1行ずつ移動 — Alt+↑ / Alt+↓
    • 
    
  • × 削除
    • 
  


  
マクロと揃えている挙動

  
    
    
  • 出力対象はCommentが入っている最後の行まで。それ以降の行は、数値が入っていても出力されません。
    • 
    
  • 途中のComment空欄行はスキップされず"Comment":""として出力されます（左端に▲を表示）。
    • 
    
  • 空欄の数値項目は 0 に置き換わります。
    • 
    
  • ACAFが空欄なら CoordCorrectInfo は {} になります。
    • 
    
  • 改行コードはCRLF、文字コードはBOM付きUTF-8。
    • 
  

  
「Commentをエスケープ」は元マクロには無い追加分です。Commentに " や \ を使うとマクロの出力はJSONとして壊れるので、必要なときだけ入れてください。
